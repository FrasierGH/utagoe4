♪ How to use Utagoe Rip ♪ Ver.3.0

Utagoe Rip tries to extract just the vocals by subtracting the karaoke (instrumental) track from the original song (vocals + music).

First, prepare the original and the karaoke as audio files. Utagoe Rip 4 reads WAV (any bit depth), FLAC, MP3, AAC/M4A, ALAC and WMA, and converts a karaoke at another sampling rate or channel count to match the original. Lossless files give the best results.

  1. ①Drag & drop the original audio file (with vocals) onto the top box.
    You can also click the folder button to choose the file.
  2. ②The karaoke file is filled in automatically.
    If it picked the wrong one, drop the correct file onto the second box.
  3. ③The name of the vocal file to create is filled in automatically.
    Change it if you'd like a different name.
  4. ④Click the Start button.
    Wait a while until it's done.
  5. ⑤When it's finished, listen with the speaker button.
Want finer control? See the settings below.

The Settings window

Click Settings... to open the Settings window.

Intro Analysis

Detects where the original and the karaoke tracks start, and corrects for the difference.

Automatic
Chooses the method automatically.
Normal
For ordinary songs.
Detailed
Also handles songs that start with vocals right from the beginning, and the like.
None
No correction.

Extraction Method

Chooses how the vocals are extracted.

By Frequency
Extracts by analysing frequencies. The sound quality may change.
By Waveform
Extracts by subtracting the waveforms. Noise tends to remain, but some songs come out well.

Accuracy Priority

Adjustable when extracting By Frequency.

Quality
Keeps the original sound quality as much as possible. Some of the music may remain.
Extraction
Gives priority to removing the music. The sound quality changes more easily.
Extractable Level
Adjusts the strength of the extraction.

Instrumental Level Adjustment

When extracting By Waveform, adjusts the level (volume) of the karaoke relative to the original.

Automatic (Averaged)
Sets the level from the average over the whole song.
Automatic (Adaptive)
Adjusts the level for every processing block.
Manual
Set the level by hand. It's centred on 1.0; larger values mean a higher level.
None
No level adjustment.

Time Shift Correction

Corrects timing differences between the original and the karaoke.

Automatic
Chooses the correction range automatically.
Manual
Set the correction range by hand. Larger values can correct larger shifts. If there's no shift at all, 0 is allowed too.

Reset

Returns the settings to their defaults. The Misc tab settings are left as they are.

Advanced

Processing Mode

How the audio is processed for the time shift correction. Change it if Normal doesn't work well.

Normal
Processes the audio as it is.
L/R Difference
Processes using the difference between the left and right channels.
Mono
Mixes stereo down to mono for processing. The result is mono.

Instrumental Phase

Once in a while a karaoke track has the opposite phase to the original, so you can choose how to treat it.

Automatic
Works out the phase automatically.
Positive Phase
Treats the karaoke as being in phase.
Inverted Phase
Treats the karaoke as phase-inverted.

Filtering

Applies filters to the output.

Extraction Centralization
Extracts the sound near the centre of the stereo image. Set the strength with the slider.
Low Pass Filter
Cuts sound above the selected frequency.
High Pass Filter
Cuts sound below the selected frequency.

Oversampling

Interpolates the data when extracting By Waveform. This can slightly reduce high-frequency noise. Higher multipliers interpolate more smoothly, but processing takes longer.

Block Length

The unit the processing works in. Time shift correction and level adjustment are done block by block. Normally there's no need to change it.

Misc

Search For Instrumental File

Finds and fills in the karaoke file automatically. It's chosen from files with similar names in the same folder as the original, so it won't always pick the right one.

Automatically Name Output File

Names the vocal file automatically: the original's file name plus the text to append. Characters that aren't allowed in file names ( \ / : * ? " < > | ) can't be used in that text.

Improved extraction (Utagoe Rip 4)

Not in the original. The new extraction matches EQ and level differences between the two releases, follows timing drift and speed wobble, and detects an inverted karaoke by itself. Where the two releases match, it subtracts cleanly instead of deleting whole frequency bins, which keeps much more of the vocal. It's on by default. While it's on, the settings it takes care of are greyed out (Intro Analysis, Time Shift Correction, By Waveform, Instrumental Level Adjustment, Processing Mode, Instrumental Phase, Oversampling and Block Length); Extractable Level (how strongly leftover instrumental is faded out), Accuracy Priority and Filtering still apply. Turn it off to get exactly the original's processing.

If something goes wrong...

The music doesn't disappear well

Try extracting By Waveform to find out why. If it sounds doubled, as if two copies are slightly out of step, see "It sounds doubled" below. If nothing is out of step, that song is probably hard to clean up completely. Try By Frequency with the Extraction priority and a stronger Extractable Level, or turn on Extraction Centralization.

It sounds doubled

The time shift correction has failed. Set Time Shift Correction to Manual and increase the range. You can also try a Processing Mode other than Normal, or set Instrumental Phase to Inverted Phase. If it's out of step right from the start of the song, try a different Intro Analysis setting or a longer Block Length.

A particular instrument is left over

That instrument is probably only in the original or only in the karaoke, or its pan (left/right position) or phase differs between them. It's hard to remove in principle, but try By Frequency with the Extraction priority, the Mono processing mode, or Extraction Centralization.

I want to process WAVE files whose starts I've lined up myself

Set Intro Analysis to None.

I only want Extraction Centralization

Enter the same file as both the original and the karaoke. You'll get the original with the filtering effects (Extraction Centralization, Low Pass Filter, High Pass Filter) applied.

The automatic analysis is slow

It's there to save you from adjusting the parameters by hand, so please bear with it. To skip the automatic analysis, set every automatic parameter to manual. Once a song has been analysed, running it again with changed parameters doesn't repeat the analysis, unless you change the Processing Mode or the Block Length.
